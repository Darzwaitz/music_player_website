# music_player_website
A Single Page Application for web, built from scratch without a framework, designed by me and built for a client with the main functionality being a music player for his music and clickable playlist
- Also includes a contact form, youtube embedded playlist and other sections that load asynchronously, so music being played via the player will not be interrupted when navigating the site.
- The website utilizes jQuery and Vanilla JS, and along with HTML and CSS, PHP is also used in the code.
- CSS Grid is utilized for the efficient responsiveness of the site on mobile devices.
- [This website is live (on a sub-domain) and can be viewed by clicking here](https://graceunderpressure.darrenkellyweb.dev)
